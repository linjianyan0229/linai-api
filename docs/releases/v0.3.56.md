# LinAI API 0.3.56

同步原项目 [Wei-Shaw/sub2api](https://github.com/Wei-Shaw/sub2api) 的 `main`，截至提交 [d851a3847](https://github.com/Wei-Shaw/sub2api/commit/d851a38477597157e78450d30af2d8504764d085)（2026-10-30）。从上次共同基线 `8f2cbb53d` 起，共合并 125 个上游提交、415 个文件的变更，涵盖上游 v0.2.18、v0.2.19 及之后的 MCP 和安全修复。本项目从 v0.3.55 升级为 v0.3.56。

## 功能与差异

| 范围 | 本次合并的功能与修复 | 与本项目的衔接 |
| --- | --- | --- |
| 管理 MCP | Streamable HTTP、OAuth 授权码与 S256 PKCE、个人/管理员和只读/读写权限、授权撤销、限流与审计 | 接入现有用户和管理路由；默认关闭，配置 `MCP_PUBLIC_URL` 后开放入口，详见 [MCP 文档](../mcp.md) |
| 管理员 API Key | 按操作和资源范围授权、到期时间、IP 白名单、摘要存储和撤销审计 | 保留本项目的版本检测、可选安装及独立重启流程，并接入新的权限校验 |
| 图片计费 | OpenAI/Composite 分组按实际返回的图片张数计费；修复 Gemini `fileData` 图片漏计费及按次图片档位的 token 记录 | 新的按张计费开关默认关闭；保留现有计费模式 |
| 模型与账号 | GPT-6.1 Terra、Vertex 账号配额上限、Grok 模型目录同步与差异诊断 | 新账号表单功能与液态玻璃控件一并保留 |
| Gemini | 可配置同账号重试次数、显式缓存重试、模型列表更新、分组生图开关 | 同账号重试默认 4 次、可配置 0–10 次；账号声明模型映射时按映射返回列表与详情 |
| OpenAI/DeepSeek/Anthropic | OAuth 非流式 SSE 转 JSON、Codex 重试、DeepSeek 角色/缓存命中/定价修复、断开连接及异常流的用量结算 | 采用上游网关、计费和调度修复 |
| 稳定性与安全 | 分页溢出、图片上传截断、频率型 429 冷却、调度缓存及并发快照修复 | 升级 Go 1.27.3、Node.js 24、vue-i18n 11、DOMPurify 3.4.17、MCP SDK 1.4.1 及相关依赖补丁 |

## 保留的定制功能

- 全站液态玻璃样式、黑色深色主题、侧栏动效及表格固定列配色。
- 顶栏公告上下轮播、点击展开；保持已删除箭头及播放/暂停按钮的界面。
- OpenAI 监控的糖果降智检测：按监控模型运行、十分钟一次、管理员自行开启，历史和可用率独立。
- 从本仓库 GitHub Releases 检测新版本，由管理员选择安装，并单独确认重启；Docker 数据卷中的更新持久化。
- 管理员引导提醒、引导复现入口及部署运营承诺书继续保持删除状态。新增 MCP 路由复用现有鉴权、权限和审计，不依赖已删除的承诺书拦截。
- 修正在线更新与糖果检测代码中资源关闭、临时文件清理结果的显式处理，完整 Go lint 为 `0 issues`。

## 升级说明

- 启动时自动应用新增的 Gemini 分组生图、权限管理员密钥、按张计费和 MCP OAuth 迁移。
- 现有 `246_channel_monitor_candy.sql` 的文件名和内容保持不变。上游 `246_enable_gemini_image_generation_groups.sql` 使用独立文件名，迁移器按完整文件名记录并校验，两者均可应用。
- 已有 Gemini/Antigravity 分组的生图开关由迁移开启；混合分组如需 Gemini 生图，请在分组设置中开启“允许当前分组生图”。
- Gemini 默认模型列表已移除停用的旧模型；仍需使用这些模型时，可在账号白名单或模型映射中显式配置。
- Grok Fast、DeepSeek 和图片结算包含上游计费修复，升级后对应请求会按修复后的规则计费。
