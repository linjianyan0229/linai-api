# 用户排行榜

登录后的用户可从侧边栏“排行榜”进入 `/leaderboard`。
展示前 20 名用户的用户名、累计 Token、累计实际消费额度（USD）。
默认统计所有模型；模型筛选为单选，选中后只统计该请求模型的调用记录并重新排名。

- 按总 Token 降序，同 Token 时按累计额度降序，再按内部用户 ID 确定稳定顺序。
- Token 包括输入、输出、缓存创建和缓存读取，不重复加入缓存时长细分。
- 总额度使用 `actual_cost`，属于累计实际消费，不是账户余额、充值额或上游成本。
- 模型优先使用 `requested_model`，历史缺失记录回退到 `model`；不展示内部模型映射。
- 只统计未删除且状态正常的用户。有 Token 的免费调用和有实际计费的调用均参与；全零失败占位记录不参与。
- 未设置用户名时显示“未设置用户名”，不会回退显示邮箱。
- 统计范围为当前保留的用量记录；清理历史用量后对应数据不再参与。

接口 `GET /api/v1/leaderboard?model=...` 需要登录，只返回排名、用户名、Token、消费额度和模型筛选选项。
不返回用户 ID、邮箱、账户余额、API 密钥或调用明细。接口固定最多 20 名，不接受客户端扩大数量。
模型为参数化精确匹配，最多 100 字节，重复传入 model 参数会被拒绝。

数据最多缓存 1 分钟，并合并并发相同查询。缓存条目有上限，接口沿用面板重查询限流。
无需数据库迁移，使用现有模型索引与用量表。
